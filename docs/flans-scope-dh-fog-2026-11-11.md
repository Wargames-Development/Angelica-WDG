# Private Flans scope DH terrain candidate

Angelica 2.2.14_X7 pairs with FMUR 1.8.06_X210-pip-scope-test. This is a candidate awaiting in-game fog acceptance, not a main-branch promotion. The existing X6/X209 baseline remains the rollback point.

The additive `FlansScope` API v1 extension exposes `hasDistantTerrain`, balanced `beginDistantTerrain`/`endDistantTerrain`, and per-container `distantTerrainOffset`. It only accepts submissions inside the active private scene callback. Pass 0 must precede `beginTranslucents`; pass 1 follows it and precedes final composite. The caller retains ownership/read locks on DH's integer position/extra and normalized-colour terrain buffers. Older FMUR clients keep their existing forward callback behavior.

`ScopeDistantTerrain` owns pack terrain/water programs and full/opaque depth textures sized to the scope. It does not use `DHCompatInternal`'s primary framebuffer sizing or global override lifecycle. The private pipeline binds those depths separately for `dhDepthTex0`/`dhDepthTex1`, with existing isolated DH matrix/frame history. Depths clear every sample. A scope-only native-depth discard is added by the normal GLSL transformer; its flag is part of shader-cache identity. Primary transforms remain unchanged. Pack programs without both DH terrain and water retain the previous forward fallback.

Validation: successful production build and Java 8 artifact check; 578 root ordinary tests and 27 GL tests, zero failures/errors and six existing platform skips. The optional local-pack test compiled the BountifulStars snapshot's actual terrain/water programs. New pixel tests cover integer vertices, eight moving native edges, separate opaque/water depth and per-sample clearing. Existing primary state/pixel/history restoration tests pass. This does not certify the visible fog match, live pack options or steady-state GPU cost in the user's world.

FMUR's `docs/debugging/scope-dh-fog-candidate-2026-11-11.md` contains the paired hashes, full changes, limitations and in-game checklist. Check normal PiP and FLIR-off fog across the native/DH boundary in rain and clear weather; FLIR-on must keep its intentional atmosphere bypass. Check water, foreground coverage, movement, close/reopen, resize, pack reload, reconnect and primary-view integrity. Actor material/shader lighting parity and WGQOL local mist acceptance remain separate.
